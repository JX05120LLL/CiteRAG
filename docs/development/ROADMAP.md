# CiteRAG 开发路线

状态：**M0 进行中，未通过整体验收**。项目名称 CiteRAG、A 版桌面 UI、第二款 B「回响」无字 Logo 已确定。本轮按最新决定调整为本地单用户基础；文档中的容量、质量和性能数字均为待验收目标。详见 [M0 验证记录](M0-VALIDATION.md) 与 [范围调整计划](M0-LOCAL-SINGLE-USER.md)。

## 实施依据

- [本地单用户首版 PRD](../多模态知识助手_PRD_v0.2_单企业首版.md)：产品范围与验收标准，保留历史文件名。
- [技术选型与架构设计](../多模态知识助手_技术选型与架构设计_v0.1.md)：技术路线、模块和数据契约。
- [选定 UI](../../design/ui/README.md)与[品牌资产](../../assets/brand/README.md)：视觉实施基线，示例内容不代表实测结果。

首版为本地单用户，无注册、登录、管理员或账号管理；使用者管理自己的知识库，服务仅运行于回环地址。前端为原生 TypeScript + HTML/CSS。一个聊天固定一个知识库；知识库、聊天与附件归同一本地安装；通话中新文字或图片提问须先挂断；图片不自动入知识库；资料维护期间暂停该库问答。未来多用户另行设计。

## 按阶段补齐资料与配置

2026-09-22 已确认按 LiveRAG 默认模型选择：百炼 `qwen-flash`（最终回答）、`qwen-plus`（引擎）、`qwen-max`（会话摘要）、`text-embedding-v4`（目标 1024 维）；语音使用火山 `bigmodel`、MiniMax `speech-02-turbo` 与本地 Silero VAD。先准备百炼 API Key，语音凭证可留到 M2。详见 [申请清单](LOCAL-DEVELOPMENT.md#模型服务准备2026-09-22-确认)。

LiveRAG 默认配置未覆盖真实重排和 VLM：模型待确认，CiteRAG 的相关范围与验收条件保留；不能因重排只有开关而勾选 M0 通过，也不提前调用未配置服务。

| 阶段 | 需准备的资料与配置 |
|---|---|
| M0 | 合法文本样例、预期问答与来源；LLM、Embedding、重排账号能力、处理区域、限额与预算。 |
| M2 | ASR、TTS 服务能力；LiveKit 本地运行条件和真实浏览器音频测试环境；本机媒体连通性。 |
| M3 | 视觉模型能力、合法图片样例及期望识别字段。 |
| M4 | 本机运行配置、磁盘限额、独立备份目的地与空环境恢复条件；不需要服务器或域名。 |

技术文档中的供应商、模型 ID 和容量均须实际验证。凭证只进入本地受控后端配置，不写入仓库、文档或聊天正文。毕设实验另行确认合法训练数据、算力与导师认可的训练对象；云 ASR 不能替代训练实验。

## 验证原则

开发与验收样本分开，记录模型、引擎提交、配置、期望来源和失败。优先验证隔离、保存、删除及精确编号边界，再评估回答质量与时延；未经实测不将目标写成已实现能力。历史设计文件描述的是设计交付时状态，当前完成项及缺项以本清单和验证记录为准。
