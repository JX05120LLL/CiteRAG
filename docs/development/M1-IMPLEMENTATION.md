# M1 分步实施计划

日期：2026-09-24。用户明确授权先推进 M1；Embedding 超长输入边界继续暂缓且未通过，M0 保持未完成。**M1-1 已实现并通过本机验证，完整 M1 未完成。** M1 完整目标仍是四类文件入库、一般/精确文字问答、可核查来源、聊天保存和维护修复。本文件按可验证切片推进，不把第一片当成整个 M1。

## 四步计划

1. **M1-1 知识库管理（本片）**：创建、改名、列表真实持久化；建库 UUID 幂等键、并发去重、5 库上限；空库不可建聊天。验证真实隔离 PostgreSQL、前端交互与错误边界。
2. **M1-2 受管资料与任务**：四类文件检查、可靠落盘、解析、来源映射、持久任务、维护门禁和串行引擎变更；先补 `active_workspace` 到引擎实例选择的通路，再开展重建。验证预检失败不封库、修改失败/中断 blocked、来源隔离及重启恢复。
3. **M1-3 文字与证据**：一般检索与固定属性精确路径、来源验证、回答状态、消息/attempt 持久化与幂等、近期上下文及摘要失效。真实模型验收须另获授权；验证编号边界、无证据/故障区分、保存失败与重启继续。
4. **M1-4 维护修复与整体验收**：删除、替换、重试、重建、旧回答遮蔽及迟到输出阻断；按 PRD 相关用例完成文件→问答→重启继续，并验证失败、删除和修复。通过后才可标记 M1 完成。

## 第一片范围和接口

本地单用户直接创建、查看和改名自己的知识库。所有新库为 `empty`；创建库不初始化引擎、不上传资料，也不把库标为 `ready`。界面继续说明空库尚不可问答，上传、任务、问答等入口不虚构成功。

- `POST /api/knowledge-bases` 接收 `name` 与客户端 UUID `client_request_id`。名称经校验并去首尾空白后保存；同一归属、同一键和同一初始创建名称返回同一库，同键不同创建名称返回冲突。库被改名后，重试仍与持久保存的初始创建名称比较。
- `PATCH /api/knowledge-bases/{id}` 修改名称；保持库 ID、状态、引擎空间及创建幂等记录不变。
- `GET /api/knowledge-bases` 返回当前本地归属下实际列表；空列表与请求失败分开显示。名字允许相同，内容身份由库 ID 和创建幂等键区分。
- 同一安装最多 5 个库。创建时在事务内串行检查重复请求和容量，重复成功请求在到达上限后仍返回既有库；并发新请求不能越过上限。
- 前端在同标签页 `sessionStorage` 保存未确认创建的名称和请求键；响应丢失或整页刷新后提供手动同键重试，不自动提交。关闭标签页或清除存储后不保证恢复该请求。
- 服务器继续校验本地来源与归属，拒绝未归属旧资料；`empty/maintaining/blocked` 库不能新建聊天。

## 迁移、风险与运行边界

追加业务迁移 `0003_knowledge_management`，为 `knowledge_bases` 增加 nullable `create_request_id UUID` 和 `create_request_name varchar(120)`，并建立本地归属与创建键唯一约束。旧库两列保持 NULL，不认领、不重写既有记录。使用过创建键的记录存在时拒绝 downgrade，避免回退擦除幂等历史；不改引擎库。

本轮只在隔离测试库验证新库升级、重复升级、旧记录保留和回退门禁，不升级真实业务库，不重启既有 8000 服务。新代码需要显式执行迁移并重启后才可使用；旧服务报告的 `database/models/rag=available` 只对应旧运行基线。schema 版本不匹配时启动应拒绝，不自动迁移。

已发现的后续前置风险：当前 `EngineManager.get(kb_id)` 根据库 UUID 推导空间，尚未使用数据库 `active_workspace`。M1-2 必须修复并验证持久空间切换和重启行为，才能实现安全重建；本片没有修复该风险，也没有开放重建。

本轮新增真实模型请求为 0，不承接之前的请求预算授权，不 commit、push 或部署。专用测试、截图和运行产物仅在本机保留。验证结果见 [M1 验证记录](M1-VALIDATION.md)。

## 第一片验收

- PostgreSQL：新迁移及重复迁移、旧记录保留；创建/改名/列表刷新后仍在；相同键并发只建一个库，同键不同名称冲突，改名后的原请求重试有效。
- 容量与绑定：并发新增不超过 5 库；满额后幂等重放有效；空库不能创建聊天，旧资料和错误 Origin 不可访问。
- 前端：创建与改名有保存中/失败/重试反馈；不重复提交，失败不添加伪成功项；特殊名称按文本显示；桌面和小屏可操作。
- 检查：后端 Ruff/编译/迁移 SQL、本机针对性测试、前端类型/构建和本机交互测试、真实隔离 PostgreSQL/API/浏览器、文档链接与 diff。检查结果按证据分层记录，不以模拟结果代替真实数据库或模型验收。
