## 发现及修复

1. **凭证已保存但正式配置未加载**：显式启用 `CITERAG_VOICE_ASSISTANT_ENABLED=true` 后，`Settings.from_env()` 使用既有 ACL / Windows DPAPI 加载器读取缺失的语音凭证。环境变量优先；默认关闭时不读取；旧 App ID + Access Token 成对加载，不混用新 API Key。缺失或损坏继续 `not_configured`，不输出秘密或底层凭证诊断。真实本机配置只做存在性确认，两份均成功加载；新增 5 个无供应商回归。
2. **连接开始瞬间误报“助手未配置”**：配置已就绪而会话仍连接时改为“等待助手就绪”；媒体配置/助手配置与实时连接状态分别显示。新增状态回归。
3. **点击来源下载导致通话断开**：原链接触发 `beforeunload`，LiveKit 默认页面离开处理断开媒体。补上原文件名 `download` 属性；在真实 Chrome 中复测，下载成功、不触发页面离开、通话仍就绪。保持真正切页的清理行为。新增下载回归。

下载原文的 SHA256 与实际原文一致：`efcc52c8b2f12d66f08ab3ddbf842da96f244e13e4043d5a47c95b68c2d27cddd`。

隔离验证中保留所有失败记录：初始原文夹具路径不符 `.source` 规范，修正测试准备后实际下载通过；初次下载意外断开通话后，测试脚本仍提交了“公开合成文字门禁测试”，此时已结束的会话不能作为通话中门禁证据。隔离服务不提供语义引擎，该条记录为 `retrieval_failed`、无来源，截图保留。随后稳定连接下重新请求文字及第二控制端，均实际返回 `409 voice_active`，无新增模型调用。两次浏览器脚本因窗口审计对象失效、精确按钮名遗漏图标而失败；重新读取页面状态、重新安装审计并用实际按钮执行后才记为通过。来源焦点在关闭动画后复查，不能用点击后立即采样判断。
