# CiteRAG · B 版设计说明

日期：2026-09-27。用户已选择 B，正式入口已迁移；本轮未选 A/C 已删除。

## 对话优先

桌面 82px 浅色导航保留文字标签，聊天内容居中，工具按需打开。聊天历史与来源使用抽屉；知识库/资料和任务是完整页面，降低问答时的信息干扰。当前固定知识库常驻上下文和输入区；单输入框自动路由，不要求用户填写精确查找条件。

手机使用顶部导航按钮、抽屉与单列资料卡；不将桌面侧栏压缩到窄屏。390px 与320px可滚动查看长文本、分页和详情；来源关闭恢复焦点。输入框和消息共用内容宽度。

## 资料与状态

资料使用列表卡、真实分页、删除记录折叠；活动任务常驻、历史折叠分页。保持上传受理、解析、索引、核验完成、失败的不同语义。失败原因只使用既有安全错误映射，恢复入口受 can_retry、清理信息、维护与 busy 门禁控制。

系统状态用 Descriptions / Tag / Alert，配置、未验证、可用、未启用、未配置独立展示。不增加账号、角色、无实际意义的统计。

## 官方 LiveKit 融合

参考固定 MIT 的 LiveKit agent-starter-react 欢迎布局和会话控制区。欢迎静态五柱、明确开始按钮；连接后实测音量、静音/播放/挂断、安全错误、返回和状态入口。保持 CiteRAG 回响 Logo、中文、当前聊天和固定知识库。

官方示例的 Next.js、Cloud Token、视频/屏幕共享、独立 Agents 后端未采用；React Voice 只负责视图，现有控制器拥有媒体。尚未实现的 ASR/TTS/字幕/助手明确说明，未用动画或模拟输出填空。

## 统一设计系统

ConfigProvider + XProvider，共用 B tokens：主色 #24765d、背景 #fafbf9、10px 控件圆角、系统中文字体。按钮、Tag、Alert、Drawer、Modal、Form、Upload、Pagination、Sender、Bubble、Conversations 使用安装版本的组件；少量 CSS 管理布局和真实音量。

只读设计与正式视图共用主题和 Voice；显式合成标签、禁用说明保持可见。设计状态只用于比较，不是连接或业务成功证据。

## 已迁移范围

正式主入口、聊天与来源、知识库/资料、任务与详情、状态，以及工作台语音和独立 voice.html。保留单控制器状态、现有 API/SSE 与维护/归属门禁；原生适配器保留兼容回归，未挂载第二套正式 UI。
