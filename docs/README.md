# CiteRAG 文档导航

当前阶段：**M0 未完成；M1-1 至 M1-4 本机主链路已实现，完整 M1 未验收**。最新本机改动增加回答模型 SSE 增量、逐段原文前缀检查和 `partial` 持久状态；临时片段不算已核验回答，来源只在最终校验并提交后展示。此前已接通断线恢复、180 天保留、停写门禁和可选每日备份/空环境恢复。入库、问答和备份默认关闭，真实模型端到端仍须另获授权；详见分层验证。

此前接手时 8000、5174、55432 不可达，未读取实际业务库 schema；更早的 `0002` 为历史核查。`0004`—`0007` 仅在隔离库升级，真实业务未迁移、旧 API 未重启。固定 SDK＋隔离 PostgreSQL 使用本地模型替身，新增真实模型请求为 0；M0 五模型及真实双库证据沿用，超长 Embedding 输入仍暂缓未通过。首版保持本地单用户、免登录、原生 TypeScript 与「回响」Logo；知识库、文字工作台、资料任务详情和系统状态的当前 UI 见 [运行界面说明](../design/ui/RUNTIME-UI.md)。

上述不可达是前一轮收尾快照。本轮开始时 8000 是隔离手工 API、5173 是本仓库 Vite；没有读取或迁移实际业务库。本轮只读检查和浏览器结果见 [M1 验证](development/M1-VALIDATION.md)。
