# CiteRAG 品牌资产

已选定 **回响**：两段相互呼应的弧面组成独立标志，表达聆听与连续对话。标志不含项目名称或字母；CiteRAG 是项目名，可在界面中与标志分开排布。

| 用途 | SVG | PNG |
| --- | --- | --- |
| 浅色背景上的黑色标志 | [mark.svg](mark.svg) | [mark.png](mark.png) |
| 深色背景上的反白标志 | [mark-inverse.svg](mark-inverse.svg) | [mark-inverse.png](mark-inverse.png) |
| 含深色圆角底的应用图标 | [app-icon.svg](app-icon.svg) | [app-icon.png](app-icon.png) |

浏览器图标：[favicon.svg](favicon.svg)。

## 规格

- SVG 画布为 **80 × 80**，由可编辑路径构成，无文字节点、字体或外部资源依赖。
- PNG 为 **512 × 512 RGBA**；独立标志背景透明，应用图标含深色圆角底。
- 黑色为 `#171717`，白色为 `#FFFFFF`；不使用渐变、阴影或描边。
- 保留画布内边距、图形比例及两段弧面之间的留白，不裁切、拉伸或拼入字母。
- 产品页头建议使用 24–32 px，浏览器图标使用 `favicon.svg`。

这些文件为当前正式选用的品牌资产。此前探索中的 A、B、C 仅是候选编号；“回响”是图形概念名称，不是项目的另一个名称。
